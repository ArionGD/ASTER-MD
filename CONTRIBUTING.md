# Contributing to ASTER MD 🚀

Thank you for your interest in contributing to **ASTER MD**! We welcome bug reports, feature requests, documentation improvements, and code contributions.

---

## 🛠️ Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) v18+ & npm
- [Rust](https://www.rust-lang.org/) v1.75+ & Cargo

### Running Locally
```bash
# Clone the repository
git clone https://github.com/ArionGD/ASTER-MD.git
cd ASTER-MD

# Install dependencies
npm install

# Run application in development mode
npx tauri dev
```

---

## 🌿 Branching & Pull Request Process

1. Fork the repository and create your feature branch (`git checkout -b feature/my-cool-feature`).
2. Ensure code compiles cleanly without errors (`npm run build`).
3. Commit your changes with clear, descriptive commit messages.
4. Push to your branch (`git push origin feature/my-cool-feature`).
5. Open a Pull Request on GitHub describing your changes and technical motivation.

---

## 🎨 Code Style Guidelines
- **TypeScript / React**: Use functional components, explicit TypeScript interfaces, and Tailwind/utility classes matching the existing design system.
- **Rust**: Follow standard `rustfmt` formatting conventions.
